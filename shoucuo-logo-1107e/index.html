Logo 第五轮：R4 字体 + 精简标志 / 三个新方案

五个方案都原样使用你选的 R4 银白字（同一套笔画，副标题也是从原图里裁出来重新排字距的，不是重新生成的）。标志和线条都直接用代码画，字后面没有任何东西。每个字都放大核对过，只有完整游戏名，没有宣传语。
推荐：想要一个标志，就选 R4a（缩到 64 像素依然清楚）；不要标志，就选 N3 纯字（最精致）。N4、N5 是同一套字的换色版本，可以按你喜欢的颜色来选。

标题页总览（现版 / 上一轮 R4 / R4a / R4b / N3 / N4 / N5）

R4a 环与阶（R4 精简版）

用 4 笔线条：一个扁平的光环（原初源泉），下面两条线收成一个窄三角形（天阶），尖端碰到光环，环中心一颗小四角星。宽度只占字的约四分之一。
特点：缩到 64 像素依然清楚，是带标志方案里最稳的。

R4b 光与三阶（R4 精简版）

用 5 笔线条：一个细光环，一道光竖直穿过，下面三级逐级变窄的台阶。
特点：缺点：缩到 64 像素时，三级台阶很像汉字「三」，可能被误读成文字。

N3 纯字 · 银白

不要任何标志，只靠字本身：副标题字距拉宽，夹在两条和标题一样宽的细线之间，「搓魔」背后一点柔光。
特点：最干净，最像 3A 大作那种只用字的标题。

N4 余烬 · 香槟金

同一套字改成哑光的香槟金（不是亮黄色），唯一的点缀是「法」字右上角一颗发光的小火星，意思是「从一颗小火球开始」。
特点：最温暖，放在紫色画面上很协调。

N5 月银 · 冷月银

同一套字改成冷冷的月光银色，边缘一点淡淡的蓝紫光；标题下一条两端渐隐的细线，中间一颗小四角星，副标题在线下面。
特点：最冷、最优雅。
