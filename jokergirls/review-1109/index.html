命运牌 · 结局改版：暧昧结局 + 恋人结局

先看现状，再选 5 项。选完点底部「复制我的选择」，发回对话。

0现在是怎么算的（不用选）

  • 好感 = 牌技分 + 心意分 + 礼物分，三项各 0–100，合计最多 300。剧情季开了以后九位都按 ×3 计分。
  • 牌技分：她坐镇的第 3 轮赢一场 +3（分数是目标 2/5/10 倍再 +1/+2/+3，最后一手打她最爱的牌型 +2），她的 3 个隐藏任务每个 +5，再 ×3。
  • 心意分：初见印象（绫香 −30、薇拉 −50、莱拉 −40 …）+ 剧情选项（每题 +8 / +2 / −5），再 ×3。
  • 礼物分：送礼（喜欢 +2、一般 +1）和女主应援（看视频，每票 +1），再 ×3；礼物只从每日任务、成长任务、成就来。
  • 结局在第 8 站夺冠时一次定好，只看总分：≥200 恋人、140–199 中间结局（每人名字不同，比如绫香「宿敌」）、<140 错过。定了以后不会再变。
问题：
  • 恋人太容易：心意分只要选对 8～9 题就满 100，再加一季正常打下来的牌技分（约 40～60）和一点礼物分，总分就过 200。三项不用都高，靠心意分一项就能撑起来。
  • 季后分数基本不动：一季只讲一个人，她只坐 2 场（莱拉 4、麦迪逊 3）。季结束后她不再坐镇，牌技分就涨不上去了；心意分只能靠回忆里改选（后悔药）。如果恋人改成「季后再达成」，要给牌技分开一个季后来源。
  • 恋人没有额外剧情：三种结局只是季终那一段不一样，恋人结局没有后续故事。

1季终结局的档位

夺冠时出的结局。你说的是「暧昧结局」和「恋人结局」两种，恋人结局在暧昧结局之后再达成。

A 季终一律是暧昧结局（推荐）

夺冠必出暧昧结局（用现在的「中间结局」改写），原来的「错过」去掉。好感低时暧昧结局换一版更克制的台词，不另算一种结局。

B 保留「错过」作为低好感结局

好感不到 140 出「错过」，140 以上出暧昧。错过的人以后也能补到恋人，只是要先补回暧昧的门槛。

2恋人结局的门槛（三项都要达到）

三项各 100 分封顶。门槛越高，越要靠季后补分（任务送礼、应援、后悔药改选、恋人篇对局）。

A 宽松：牌技 60 · 心意 80 · 礼物 50

认真打完一季、选项大多选对，再送几天礼物就能达到。

B 标准：牌技 75 · 心意 90 · 礼物 70（推荐）

一季打完大多只够暧昧；要做完她的隐藏任务、选项几乎全对，再攒一周左右的礼物或应援。

C 严格：牌技 90 · 心意 100 · 礼物 90

选项必须全对（或用后悔药改到全对），礼物要攒两周以上。适合做长线目标。

3恋人篇怎么触发

暧昧结局之后，三项达标才开「恋人篇」，再加一道触发难度。

A 告白局：她亲自坐一场特别对局

三项达标后，她在房间留言「有话想当面说」。之后开一局「告白之夜」：她坐第 3 轮，难度高一档（比她那一季高 1 个 S），最后一手要打出她最爱的牌型才算赢。输了可以再来，每天 3 次。

B 三晚约会：连着三天，每天一段

三项达标后，每天能约她一次，三晚各有一段剧情和一个牌局小目标（比如「用对子赢下第 3 轮」），中断了要从第一晚重来。

C 两晚约会 + 告白局（推荐）

先两晚约会（每天一段，带牌局小目标），第三晚是告白局。剧情最完整，节奏一天一段，也能把玩家每天拉回来。

4季后的牌技分从哪来

她那一季结束后就不再坐镇，牌技分需要新的来源，否则要求高了就补不上。

A 只算恋人篇里的对局

约会 / 告白局赢了加她的牌技分。

B 心动特训她的牌型时加

每特训一次她最爱的牌型，加她的牌技分。

C 两者都算，再加「回忆里重打她的关键局」（推荐）

回忆里能重打她坐镇过的那几局（不影响主线进度），赢了按原规则加牌技分，每天限 3 次。

5恋人篇的内容量

剧情文字照例用 gemini-4-argon 按她的剧本写，配音另说（配音任务现在停着）。

A 复用现在的恋人结局

现在恋人结局那一段（换装、告白）挪到告白局之后当终章；约会只写两段短戏。只需要写文字，不用新画图。

B 两段约会 + 告白终章，每人 1 张新 CG（推荐）

两段约会是新写的，告白终章用现在的恋人结局改写；每人新画一张约会 CG（九位共 9 张）。

C 三段全新剧情，每人 3 张新 CG

约会两段 + 告白各一张新 CG（九位共 27 张），内容最足，工作量最大。

6改版后不用选的部分

  • 她的房间加一块「恋人条件」：三条进度条、每条的门槛，告诉玩家还差哪一项、怎么补（打她的局 / 改选 / 送礼应援）。
  • 老存档：已经是恋人结局的保留；「中间」「错过」都改成暧昧结局，三项达标就能开恋人篇。
  • 恋人篇达成后：限定装扮、金色牌背、「恋人」成就照旧，房间里多一组恋人专属日常台词。
  • 大厅「下一目标」：季终后如果有女主差一点就到恋人，提示她差哪一项。
