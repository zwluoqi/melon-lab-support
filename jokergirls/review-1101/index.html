3对战流程：打完一场后的画面切换

现在打完一场要换 4 个画面：对战 → 结算 → 系统商店 → 选下一场 → 对战，每次背景、顶栏、按钮都重排，感觉被切碎。三个方案规则和数值都不变。

A · 一张牌桌打完一关推荐

始终停在同一个画面。赢了在牌桌上直接结算；牌桌下推出「补给台」抽屉买东西，买到的直接飞进栏位；收起后对手区出现下一场的对手卡和「迎战 / 跳过」。

工作量：约 2–3 轮。

B · 赛段地图

每关一张路线图（8 赛段 × 3 场 + 补给站），打完回地图点下一格。一关的整体感最强，但多一个页面、点击更多，和原作节奏差别最大。

C · 轻量过渡

还是三页，但共用同一背景、顶栏、底栏，左右滑动切换，顶部三个小点「对战 · 补给 · 下一场」。一轮能做完，但仍是三页。

先 C，再 A

这一轮先上 C 快速减轻割裂感，后面再做 A。
