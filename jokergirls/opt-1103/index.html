问题 2 · 被编辑推荐时用的是哪个资源？

主要是 16:9 宣传图 + 游戏名 + 图标。编辑推荐、专题、活动横幅这些人工位，都从「16:9 宣传图」取图，图标和名称叠在卡片上；方形位置取 1:1 宣传图。
首页「推荐」信息流（算法 + 编辑混合）用的是「首页推荐素材类型」选中的那项：现在选的是 16:9 宣传图，配推荐语；如果改成「宣传片」，卡片里会静音自动播放宣传片。

所以 16:9 宣传图和图标是被看到次数最多的两张图。宣传片如果按问题 3重剪，可以考虑把推荐素材换成宣传片（动的比静的点击率通常高），需要一张第 0 帧就很抓眼的画面。

问题 3 · 宣传片 / 实机录屏重剪方案（先看方案，确认后再剪）

现在的问题：开头慢、CG 镜头停留太久、出牌和结算的动画是原速，信息密度低。思路：第 0 秒就给大数字，女主用 CG 快切 9 连闪，战斗只留「出牌 → 数字暴涨」的高光段并加速。

宣传片（横屏 16:9，约 22 秒，放首页推荐 / 详情页第一个）

0–1.5s第 0 帧就是爆点：实机里打出的超大分数「×倍率」结算瞬间，金光 + 震屏，大字幕「一手牌，打出一个亿」。这一帧也是首页卡片封面。
1.5–5s出牌高光 3 连切（每段约 1 秒，2–3 倍速）：选牌 → 打出 → 装备连续触发跳字 → 倍率翻倍。字幕「叠倍率」。
5–7s商店 2 刀：点装备购买 → 下一手带着新装备再打一次，数字更大。字幕「爆数值」。
7–14s九位女主 CG 快切：每人 0.7 秒，卡点音乐鼓点，CG 轻推镜 + 白闪转场；每张角落标名字和一句人设：林晚晴·温柔御姐老板娘 / 西园寺绫香·傲娇大小姐 / 夏洛特·眼镜腹黑学霸 / 英格丽德·制服御姐 / 韩智雅·甜妹爱豆 / 莱拉·富婆女王 / 卡米耶·小恶魔 / 麦迪逊·金发辣妹 / 薇拉·银发冰山。最后一格 9 宫格同屏。字幕「九位女主，九段心动」。
14–18s一手打穿：Boss 关分数条一手直接爆满溢出，「胜利」，数字滚动到天文数字。
18–20s一个女主的配音名场面（例如薇拉一句原声台词 + CG），停 2 秒给情绪。
20–22s字标「小丑牌：心动牌局」+ 推荐语，音乐自然收尾，不用高亢尾音。

素材全部用现成的：实机片段 + 已有 45 张 CG，不需要再生成视频。

实机录屏（竖屏 9:16，约 30 秒，详情页第二个）

0–3s直接从一手大牌开始：同花顺打出，装备一个个触发，倍率跳到最高、分数爆表（原来开头的登录、大厅全部删掉）。
3–12s连续实机出牌 2 手（平台要求核心玩法连续 ≥10 秒）：只剪掉等待和菜单停顿，结算动画 1.5 倍速以内（太快会被认为不是实机）。
12–17s商店：刷新 → 买装备 → 回到牌局立刻用上，分数比上一手明显更高。
17–25s女主互动：大厅点女主 → 配音 + 气泡；送礼物 → 好感上涨；剧情 CG + 原声台词 + 选项（只用游戏自己的声音，不加旁白字幕）。
25–30sBoss 关一手打穿 → 胜利结算 → 32 强晋级画面收尾。

实机录屏的规则：不能另加配音、字幕、画中画；前 5 秒要有核心玩法。所以它的「抓眼」只能靠剪辑节奏，字幕和九女主快切放在宣传片里做。

另外：首页推荐素材可以考虑改成「宣传片」，让首页卡片直接播这 22 秒（第 0 帧就是大数字）。

问题 4 · 文案（3 个方案）

玩家在详情页只看前 2–3 行。每个方案都是：首页推荐语（≤25 字）+ 简介（前两行就是钩子，全文 ≈150 字）+ 开发者的话（≈120 字）。关键词记忆点统一为：叠倍率 · 一手打穿 · 九位女主 · 不逼看广告。

方案 1 · 接地气

推荐语一手牌打出一个亿，九个老婆等你回家

一手烂牌，叠到一个亿。 九个女主，个个都想娶。 ▶ 怎么玩：凑牌型、买装备、叠倍率，数字越滚越离谱，最后一手直接打穿 Boss。 ▶ 有什么：九位不同国家的女主，晚晴、绫香、薇拉……每人一条完整恋爱线，有 CG、有配音、能送礼、能约会。 ▶ 广告：只有你自己想点的那种。不看也能玩爽。 给我 10 分钟，不好玩你回来骂我。

开发者的话：

我是 FIRE 工作室，其实就我一个人。 做这游戏就一个目标：让你「再来一把就睡」，然后天亮了。 不逼你看广告，不搞虚假宣传。 好玩就给个好评，不好玩直接骂，我真的会看、会改。

方案 2 · 实诚

推荐语肉鸽卡牌构筑，九段恋爱剧情，不逼看广告

肉鸽卡牌构筑 × 恋爱剧情。一个人做的游戏，认真做的。 【玩法】用扑克牌型出牌，在商店买装备、升级牌型，叠加倍率。一局约 15 分钟，每局随机，套路自己研究。 【剧情】九位女主，九个国家的牌局，每人 5 张 CG、全程配音，羁绊满了能换装。 【良心】没有内购。广告只在你主动点的时候出现，不看广告也能通关。 不好玩的地方请直接告诉我。

开发者的话：

大家好，这是我一个人做的第一款卡牌游戏。 我自己就是挑剔的玩家，所以只做我自己愿意玩到天亮的东西：套路要自己研究出来，数字要打得爽，女主的故事要让人记得住。 游戏还有不足，评价和论坛里的每一条我都会看。 谢谢你点进来。—— FIRE 工作室

方案 3 · 女主开口（角色口吻）

推荐语「赢一手给我看看？」九位女主坐在牌桌对面

「来都来了，赢一手给我看看？」—— 林晚晴 一手扑克，九个对手，一个比一个难追。 凑牌型、买装备、叠倍率，打出让她们都愣住的分数。 晚晴的温柔、绫香的傲娇、薇拉的冰山……赢下牌局，才能读懂她们的心事。 九段剧情 · 45 张 CG · 全程配音 · 不逼看广告。 牌已经发好了，就等你坐下。

开发者的话：

我想做一款「输了想再来、赢了想看她」的游戏。 所以牌局要难、要爽，女主要每一个都让人放不下。 一个人做的，不完美，但每一行剧情都是认真写的。 有任何想说的，论坛见。—— FIRE 工作室

推荐语都 ≤25 字，没有极限词和时效词。方案 1 的「老婆」比较网络化，有被认为低俗的小风险；方案 3 用了台词引号，审核可以接受。也可以混搭，例如「推荐语用 1，简介用 3」。
