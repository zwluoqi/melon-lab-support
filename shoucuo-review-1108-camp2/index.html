手搓魔法 · 11-08 营地第二轮（待确认）

1. 掌贴掌 CG（得到新印记后回营地播放）

世界观包装：守关者交出的回答落进掌心时还「烫」，认不得他这双从泉底拼回来的手，泉水会把它冲走。薇丝塔掌贴掌替他封住，代价是每次都分出一点自己的记忆和泉水，手会变凉、微微透明，她从不说。这只手，也是那一夜伸进光里的那只手。第一次播 4 句，之后每个印记每一面各一句；两面合一、第 8 关另有一句。三张候选图，选用 b。

2. 营地：点主角打开掌心，怎么玩缩成「?」

布局沿用现在的默认，文字位置不变；印记横排已去掉。有新印记时主角身上按那个印记的颜色发光，平时只有一点微光。「?」在标题牌右侧；失败结算时左上角会出「怎么玩」。

3. 结算：魔力结晶动效

数字从 0 滚到 +N，结晶碎片从胶囊飞向总数，每落下一颗总数跳一次，最后胶囊弹一下并闪光；看广告翻倍时换成金色、碎片更多的版本。

4. 点目标文字：指引详情页

分「刚刚发生 / 你在哪里 / 接下来 / 世界观残句」四栏；还没见过的剧情不会提前写出来。「听她说」播她的配音。

5. 战斗 / 绕过，去掉看广告刷新

「选择」改成「战斗」，「绕过」和它同宽、同字号；绕过时奖励券放大弹出，配光环和碎片，再飞进顶栏。这条流程里写「跳过」的地方都改成了「绕过」。商店里看广告刷新的按钮已经删掉，免费刷新保留。
